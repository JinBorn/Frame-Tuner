# 工作台保有编辑权威，Cocos 首期消费单向烘焙导出

工作台项目保存可编辑动画数据，引擎资源包作为可重新生成的派生产物，首期不做引擎修改的反向合并。Cocos Creator 3.8.8 首期使用 TypeScript 播放组件消费资源包，将主体、图片挂件和拖尾视觉烘焙为透明帧，并独立保留时序、原点、框体和音效信息。

这一选择优先保证网页与引擎的画面一致，避免首期为各引擎分别维护拖尾网格和材质，也避免双向编辑产生的数据归属冲突。代价是图片体积可能增加，已烘焙的效果不能在游戏中单独改色或修改轨迹；原始工作台数据仍保留，允许重新编辑和导出。游戏业务逻辑应与可重新生成的适配器产物分开维护。
