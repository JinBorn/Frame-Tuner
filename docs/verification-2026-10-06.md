## 重点回归

- 刷新前检测未保存修改；取消后数据保留。慢动作的图片晚到时，不能覆盖随后选中的动作；移除唯一可见项目后，显式空重载清空旧项目状态。
- 播放保留每次刷新之间的时间余量；禁用帧不占时长。图片缓存有条目／字节限制、并发控制、活动资源保护和过期任务失效机制。
- 未知引擎不隐式路由到 Godot；损坏 JSON 明确报错并保留原文件。
- `default` 项目不会在新增项目时丢失；大小写相同的新 ID 分配独立目录；普通 `codex_pets` 项目不会被可选 Pets 功能重新分类。
- 实际 Canvas 像素检查：序列与图集一致，标记图不进入渲染，普通挂件与拖尾进入烘焙，包括完全位于初始探测画布外的挂件与拖尾；原始源文件保持可编辑。
- 导出保留不等时长、源帧映射、旋转框体与音频字节。Sheet 经 CLI 重导入可恢复原点、时长、音效绑定和音量；缺音频或不支持的图集旋转／裁剪语义在写入前拒绝。
- ZIP 的内容、CRC、路径和源素材归档通过验证。音效、图像及 Cocos 运行资源不依赖源机器的绝对素材路径。
- 使用独立 `FRAME_TUNER_ROOT` 时，用户素材仍从指定数据根读取，内置拖尾 PNG 可从仓库预设目录读取；主入口与旧 Lite 都验证了实际预设字节和访问边界。
