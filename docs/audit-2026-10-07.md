# 2026-10-07 全流程缺陷检查

本轮检查覆盖 Windows 启动与退出、更新器、项目存储、网页导入、帧编辑、保存、预览与导出、Cocos 播放组件以及主服务／Lite HTTP 接口。发现的可复现问题直接修复；沿用现有模块和暂存回滚机制，没有增加框架或产品功能模块。

## 修复与回归

| 范围 | 触发条件与修复结果 | 验证 |
| --- | --- | --- |
| 变换 | 动作缩放曾重复乘已有帧的均匀比例；部分覆盖缺少旋转时曾错误归零。现在正确保留比例、继承动作旋转，并保留显式零值。 | `transform_inheritance_browser_test.js`，原变换交互测试 |
| 时长输入 | 连续输入动作时长曾产生多条撤销记录，播放刷新也可能覆盖草稿。现在完成输入后一次应用，支持取消，输入时暂停播放；Ctrl+S 先提交当前输入，再保存。 | 真实 Chrome 的输入、一次撤销、Ctrl+S 和重载测试 |
| 挂件上传 | 上传过程中切换项目可能把图片与绑定加到错误项目。上传捕获原项目并纳入忙碌状态，阻止冲突操作；失败释放状态。 | `attachment_race_test.js` 延迟请求与失败注入 |
| 帧与特效数据 | 读取、保存或复制遗漏特效覆盖；部分保存误清未提供字段；复制漏掉旧格式绑定或重排其他项目的绑定。现在保留所有覆盖并按项目重排。 | `frame_edit_audit_test.js` |
| 写入失败 | 复制、保存、音效及批量换图可能部分落盘。现在先准备整批数据，再复用暂存提交与失败回滚；共享图片路径的冲突替换在写入前拒绝。 | 帧审计、`main_replace_atomic_test.js`、删除与导入回滚测试 |
| Windows 路径 | 保留设备名、尾部点、大小写别名及 Lite 遗留目录可能导致创建失败或目录重用。新建路径规范化并避让已有目录，历史项目不自动搬迁。 | `storage_integrity_test.js`、项目注册测试 |
| 坏数据 | 无效 JSON 结构、损坏共享拖尾预设曾可能被当作空数据覆盖；只有文件头或截断的 PNG 曾可导入。现在拒绝操作并保留原文件。 | 存储、共享预设完整性测试 |
| 本地 HTTP | 仅监听回环地址不足以防恶意网页跨站请求或 DNS rebinding。现在验证 Host、Origin 和 Fetch-Site；正常本站与本机 CLI 请求继续工作。 | `http_security_test.js`，主服务和 Lite 均测 |
| 文件边界 | 素材读取、源文件归档和换图的词法检查可被 junction／symlink 绕过。现在核验真实路径；已有音效必须是工作区内的普通文件。 | HTTP、归档、音频路径测试 |
| 上传 | 超大请求返回明确的 413；统一请求体上限为 256 MiB。坏 PNG 在覆盖原图之前拒绝。 | 超限与坏图片请求，验证原文件字节不变 |
| 导出 | 成功或失败后曾跳回第一帧；现在恢复原选中帧。合法 `..frame.png` 文件名不再被误认为越界。 | 浏览器导出事务、归档测试 |
| Cocos | 极短正帧时长配合固定浮点容差可能令 `advance(0)` 无限循环；容差改为受帧时长约束。 | Cocos 时钟测试、Creator 3.8.8 类型检查 |
| 启动 | 设置 `PORT`／`LITE_PORT` 后，启动器仍检查和打开默认端口。现在使用相同环境端口，并拒绝无效值。 | PowerShell 隔离测试，不启动真实服务或浏览器 |
| CLI／更新 | 导出参数可能被静默改成默认值；自定义 Git fetch 配置可能使更新器使用过期引用。现在提前校验参数，并使用本次获取的提交进行仅快进更新。 | CLI 输入测试、隔离本地 Git 仓库更新测试 |

## 验证方式与边界

最终结果：`npm run check` 检查 82 个 JavaScript 文件，`npm test` 的 30 组测试全部通过；`npm run test:browser` 的网页全流程和三视口检查、`npm run typecheck:cocos` 均通过。最后补充的动作时长 Ctrl+S／一次撤销／重载用例也独立通过。

所有修改数据的测试均使用临时项目根、临时仓库或安装目录。用户正在编辑的 `data/attack_trail_presets.json` 不纳入提交，也不由测试覆盖。现有网页创建、导入、调参、保存、重载、导出和三种窗口尺寸检查继续保留。

本轮运行平台为 Windows 和本机 Chrome；Cocos 使用 Creator 3.8.8 类型声明验证。绑定引擎换图走真实 HTTP 和隔离的 Godot 类型项目，未启动 Godot／Unity 编辑器重新验收游戏场景。PNG 校验检查结构完整性，不等同于完整解码或 CRC 验证。暂存回滚覆盖可捕获的写入失败，不宣称提供断电事务或多进程数据库级隔离。

这些结果说明已检查的流程及回归用例通过，不代表项目不存在其他缺陷。
